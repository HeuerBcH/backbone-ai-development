# Tickets

Fatias verticais derivadas de [`docs/specs/`](../docs/specs/), e bugs. Cada ticket entrega algo demonstrável sozinho.

| Modelo | Use para | Criado pela skill |
| --- | --- | --- |
| [`_template.md`](_template.md) | Funcionalidade | `spec-to-tasks` |
| [`_template-bug.md`](_template-bug.md) | Bug | `fix-bug` |

**Status possíveis:** `ready-for-agent` · `in-progress` · `in-review` · `done` · `blocked`

Um ticket só começa quando atende à Definition of Ready ([`docs/process/definition-of-done.md`](../docs/process/definition-of-done.md)).
