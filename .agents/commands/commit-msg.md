---
description: Prepara a proposta de commits e/ou a descrição de PR para o humano executar
argument-hint: "[pr | release — opcional]"
---

Execute a skill `prepare-commit` sobre as mudanças atuais. Se $ARGUMENTS contiver `pr`, inclua a descrição de pull request; se contiver `release`, inclua as notas de release.

Não execute `add`, `commit`, `push` nem crie PR: entregue os textos e os comandos para o humano.
