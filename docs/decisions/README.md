# Decisões (ADRs)

Cada arquivo registra **uma** decisão relevante: o contexto, as alternativas, o que foi escolhido e as consequências. Crie novos com a skill `record-decision` a partir de [`0000-template.md`](0000-template.md).

- ADRs aceitos não são editados (só correções de digitação). Mudou a decisão? Crie um novo que **substitui** o anterior.
- Status possíveis: `proposto`, `aceito`, `rejeitado`, `substituído por NNNN`, `descontinuado`.
